# Landing page draft — jroesner

A candidate impress.js landing page for
[#263](https://github.com/arena-hub/arena-hub/issues/263), giving a visual overview of the
Innovator's tech stack, architecture, deployment, and features. Per the ticket, each developer
builds their own version independently; the team compares versions afterwards and keeps one.

Self-contained — no CDN, no npm install, no build step. [impress.js](https://github.com/impress/impress.js)
v2.0.0 is vendored directly under `vendor/impress.js`.

## Run it

Open `index.html` directly in a browser, or serve the directory with any static file server, e.g.:

```bash
npx serve innovator-jroesner
```

Navigate with the arrow keys, space/page-down, or by clicking a step directly.
