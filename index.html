Ziele

  • Zentrale Web-Anwendung zur Übersicht über vergangene Projekte, Teilnehmerhistorie und Ideen-Backlog
  • Standardisierter Ideations‑Prozess inkl. Sichtbarkeit, Review, Voting und Entscheidung „Ready for ARENA“
  • Integrationsfähige Architektur (SSO, Benachrichtigungen, Collaboration‑Tools)
  • Erweiterbarkeit über Plugins, versionierte APIs und einheitliche UI-Patterns

Nicht-Ziele

  • Keine verbindliche Tool‑Migration (z. B. Jira/GitHub/Confluence) – nur optionale Integrationen

Lernziele

  • Java Backend mit Spring Boot
  • Angular Frontend und einer ausgewählten Komponentenbibliothek
  • Nutzung von KI Tools in der Entwicklung (z. B. Github Copilot, Reply Neurons)
  • Testautomatisierung über Unit-Tests und ggf. weiteren
  • Erlernen eine typischen Projekt-Struktur und Vorgehensweise bei unseren Kundenprojekten
