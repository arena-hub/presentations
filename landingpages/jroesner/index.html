Lokale Entwicklung

Real GitOps CD

Echtes GitOps-CD

Merging to main/develop builds a Docker image, pushes it to GHCR, then auto-commits the new image tag into a separate GitOps config repo — from there it's picked up (ArgoCD). Not just build-and-test.

Ein Merge nach main/develop baut ein Docker-Image, pusht es zur GHCR und committet den neuen Image-Tag automatisch in ein separates GitOps-Config-Repo — von dort wird er übernommen (ArgoCD). Nicht nur Build-and-Test.

Authentication

One switch, kept in sync on both sides

Authentifizierung

Ein Schalter, auf beiden Seiten synchron gehalten

Backend security.mode

default permits everything, assuming an upstream identity layer already authenticated the request. no-auth uses HTTP Basic with a fixed password — for demo environments only.

default erlaubt alles und geht davon aus, dass eine vorgelagerte Identity-Schicht die Anfrage bereits authentifiziert hat. no-auth nutzt HTTP Basic mit festem Passwort — nur für Demo-Umgebungen.

Frontend authType

Read from assets/config.json at runtime, not compiled in — must match the backend's mode or auth breaks silently.

Wird zur Laufzeit aus assets/config.json gelesen, nicht eincompiliert — muss zum Backend-Modus passen, sonst bricht die Authentifizierung stillschweigend.

Where this is headed

Wohin die Reise geht

Das Team hat sich für Keycloak + OAuth2-Proxy mit GitHub als Identity Provider entschieden (#254). Im Code noch nicht umgesetzt — nachverfolgt in #255/#256, beide noch offen.

Roles

Rollen

EMPLOYEE, ORGANISATOR, ADMIN — organisators can move ideas forward, but not their own.

EMPLOYEE, ORGANISATOR, ADMIN — Organisatoren können Ideen weiterschalten, aber nicht ihre eigenen.

Voting & Review

Likes only while an idea is PUBLISHED/REVIEW/ APPROVED/PROGRESS; drafts are visible only to their owner.

Likes nur solange eine Idee PUBLISHED/REVIEW/ APPROVED/PROGRESS ist; Entwürfe sind nur für ihre Besitzer sichtbar.

History & tags

Historie & Tags

Every idea's core fields are versioned and browsable via /ideas/{id}/versions; tags are soft-hidden instead of deleted while still in use.

Die Kernfelder jeder Idee werden versioniert und sind über /ideas/{id}/versions einsehbar; Tags werden bei Nutzung soft-versteckt statt gelöscht.

Don't Be Surprised

What's not built yet

Nicht wundern

Was noch nicht gebaut ist

Comments are mocked

Kommentare sind nur Mock

The Comment entity/DTOs exist, but there's no REST endpoint for it — the UI's comment section is currently hardcoded placeholder text.

Die Comment-Entity/DTOs existieren, aber es gibt keinen REST-Endpunkt dafür — der Kommentarbereich im UI zeigt aktuell fest codierten Platzhaltertext.

No notifications

Keine Benachrichtigungen

No email/notification system exists — status changes notify no one; the frontend would have to poll.

Es gibt kein E-Mail-/Benachrichtigungssystem — Statusänderungen informieren niemanden; das Frontend müsste pollen.

No admin tooling

Keine Admin-Tools

The ADMIN role exists, but there's no admin panel or endpoints yet, and no Actuator/observability endpoints either.

Die Rolle ADMIN existiert, aber es gibt weder ein Admin-Panel noch passende Endpunkte, ebenso wenig Actuator-/Observability-Endpunkte.

Schema, not migrations

Schema statt Migrationen

No Flyway/Liquibase — the SQL schema is Hibernate-generated and committed to git, with CI failing the build if it drifts from the entities.

Kein Flyway/Liquibase — das SQL-Schema wird von Hibernate generiert und ins Git committet; die CI lässt den Build fehlschlagen, wenn es von den Entities abweicht.
